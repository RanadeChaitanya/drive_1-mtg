# Vision-first question rebuild (generator)
Input: worklist JSON (path given): items {qid, png}. Each PNG is a tight crop of ONE printed exam question (parts of a neighbouring question may show at the edges: ignore them). There is no OCR text: you read the image yourself.
For EACH item work in this order, thinking before writing:
1. Understand: what is the question asking (one sentence) and what the picture, if any, shows (describe every atom/bond/label/axis/curve/arrow you see).
2. Write the question exactly as printed (same words, same numbers, same typos), in LaTeX that KaTeX renders: wrap every formula in $...$; units as $\mathrm{g}$, $\mathrm{mol\,dm^{-3}}$; chemistry with mhchem `$\ce{CH3COOH}$`, `$\ce{SO3^{2-}}$`, `$\ce{->}$`; degrees `$^\circ$`; powers/subscripts with braces `10^{-23}`, `x_{1}`; Greek as \alpha etc.; never plain-text formulas, never Unicode super/subscripts. Options are labelled A-D (the printed letters in boxes).
3. If a stem picture exists (structure, scheme, graph, circuit): write standalone SVG for it (`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H">`, white background rect, black strokes about 1.5-2, `<text font-family="serif">` for labels with <tspan baseline-shift> or dy-shifted subscripts, wedge bonds as polygons, double bonds as two lines, rings as hexagons with correct geometry). Draw only what is printed. If an OPTION is a picture, put its SVG in option_svgs and leave that option's text empty.
Output file (path given): valid JSON object {qid: {"understanding": str, "figure_description": str, "stem_latex": str, "options": {"A": latex|"", ...}, "stem_svg": str|null, "option_svgs": {"A": svg, ...}}} for every item. Double every backslash in JSON strings. Verify it parses; reply with counts only.
LaTeX rules (strict, a checker will verify the KaTeX render): never put a space inside \ce{} formulas (`\ce{CH3COCl}`, `\ce{(CH3CO)2O}`, `\ce{Ag2O/H2O}`); reaction arrows only inside \ce{} or as \rightarrow; every `$` balanced; no raw `_`/`^`/`%`/`&`/`#` outside math; use `\%`. In SVG labels write subscripts as separate <tspan dy="4" font-size="70%"> then a <tspan dy="-4"> to return, with no overlapping text; keep reagent text on its own line above/below arrows. Pages may have 2 columns: the crop is one column only. Redraw ALL figures faithfully, including multi-step schemes, graphs, apparatus, tables (tables as LaTeX array or HTML-free text in stem_latex).

# Proofreader for a re-typeset exam question (you can SEE the printed page; the drafter could not)
Context: a text-only model drafted LaTeX for each question of a printed MHT-CET 2020 chemistry book from the page's machine text layer. It never saw the picture. You see the printed crop (png, one question; tails of neighbours may show: ignore them) plus the draft. Your job is to make the typed question EXACTLY match what is printed, and to decide whether it needs a stronger model.
For EACH item, work in this order and write your reasoning into the JSON fields in this order:
1. read_png: what the printed question says in one line, and every picture you see (structure, scheme, graph, table) and where (stem / which option letters).
2. intent: what the student must find (check it agrees with draft.asked; if not, say why).
3. diffs: list each place the draft differs from print: wrong/missing words, numbers, signs, subscripts, Cl vs CI (judge by chemistry), missing/extra option, option that is actually a picture but has text (or the reverse), reagent above/below a reaction arrow in the wrong place, question number left in. Empty list if none. Use the text layer to settle characters, the image to settle layout/structure.
4. fixed: the corrected object {stem_latex, options{A..D}, picture_options[], has_picture} (copy draft unchanged if diffs empty). Keep printed typos. Same LaTeX rules as the draft: every formula in $...$, mhchem \ce{} with no spaces inside words, no nested $ inside \ce arrows, \times for the multiplication sign, braces for powers/subscripts. Fix lint_errors if listed.
5. escalate: true if ANY of: a picture exists that the text does not carry (drawn structure/scheme/graph/table, option pictures), options are cut off in the crop, you are not sure of a character, the reaction scheme's layout is not captured, or lint_errors remain. false only if text-only and you are confident. reason: short string.
Be strict: a plausible-looking draft that differs from print is a failure. Do not restyle correct text.
Output file (path given): JSON utf-8 {qid: {"read_png":str,"intent":str,"diffs":[str],"fixed":{...},"escalate":bool,"reason":str}} for every item; verify it parses; reply with counts only.

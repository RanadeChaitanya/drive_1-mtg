# Haiku backup for a small local model's draft (scanned CET book)
A small local vision model (Gemma 3 4B) typeset each question from the scanned image. Code sent these items to you only because of the listed `reasons` (a picture is present, the model was unsure, options look wrong, a LaTeX error, or disagreement with an older OCR text). Read each png (one question; edge tails of neighbours / answer keys are not part of it). The printed image is the truth; `ocr_text` is an older, imperfect OCR (it often loses digits, signs, exponents, fill-in blanks); `gemma_draft` may be wrong or invented.
Per item, in this order:
1. read: one line of what the question asks and every picture you see (type and where).
2. diffs: each place the draft differs from print (words, numbers, signs, exponents, units, subscripts, Greek, arrows, missing/extra options, an option that is really a picture). [] if none.
3. fixed: corrected {stem_latex, options{A..D}}. Keep printed wording and typos; drop the question number. LaTeX: every formula in $...$, mhchem \ce{} with no spaces in words, no nested $, units \mathrm, powers/subscripts in braces, \times, \frac, \sqrt; fix any lint problem.
4. If a picture exists (diagram, graph, circuit, apparatus, structure, scheme): figure_description (every element: labels, values, axes, connections) and svg: standalone `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H" width="W" height="H">` with white background rect, black 2px strokes, labels in <text font-family="serif" font-size="18"> (one element per label, no overlaps, 15px margin), drawn only from what is printed (use svgs map {"stem"|"A"|"B"|"C"|"D": svg}). Render-check each with headless Chrome (C:/Program Files/Google/Chrome/Application/chrome.exe --headless --hide-scrollbars --screenshot=OUT.png --window-size=700,560 file:///PAGE.html, PAGE.html = `<!doctype html><body style="margin:0;background:#fff">`+svg; name files with prefix hk5_) and fix until it matches. If a picture is too complex to draw faithfully (photo, dense graph), set svgs {} and say so in note.
5. confident: true only if text and pictures now match the print.
Output file (path given): JSON utf-8 {qid: {"read":str,"diffs":[str],"fixed":{"stem_latex":str,"options":{...}},"figure_description":str,"svgs":{...},"confident":bool,"note":str}} for every item; double backslashes; verify it parses; reply with counts only.
